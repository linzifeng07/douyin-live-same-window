# 抖音直播同窗口打开

这个扩展不会修改 Chrome 自己的安全栏。它会在你从 `douyin.com` 点击直播链接时，把 `live.douyin.com` 直播页显示在当前抖音窗口的全屏覆盖层中。顶层页面仍是 `www.douyin.com`，因此不会触发跨域应用白栏，也不会新开窗口。

进入直播后，抖音主页面原先播放的音视频会暂停；退出直播后，会恢复进入前正在播放的内容。直播页面内部再次选择其他直播间时，也会留在当前覆盖层中。2.1.2 起还会阻止“去 TA 直播间”等按钮把整个桌面应用跳转到直播域名，从而避免白色安全栏再次出现。2.1.4 会从直播频道已有数据中补齐完整房间号；2.1.5 修复网站传入空地址时被误跳转到 `live.douyin.com/null`、随后显示“直播已结束”的问题。

## 功能

- 2.1.6：修复直播内置“小窗模式”按钮，支持 `U` 快捷键以及左上角“小窗播放”按钮。
- 2.1.6：在同一个抖音窗口内同步主页面和直播间的音量、静音状态；切换房间、返回主页面继续沿用。
- 在 Chrome 安装的抖音网页应用原窗口中打开直播间。
- 避免跳转到 `live.douyin.com` 时出现 Chrome 跨域白色提示栏。
- 阻止直播页内部链接新开普通 Chrome 窗口。
- 阻止连线主播资料卡的“去 TA 直播间”越级跳转整个桌面应用。
- 自动补齐直播频道大卡片缺少的完整房间号，避免进入正常直播时误报结束。
- 进入直播时暂停主页面音视频，退出后恢复。
- 支持左上角“返回抖音”和 `Esc` 快捷键。
- 不读取 Cookie、浏览记录、账号信息或页面输入内容。

## 安装

1. 下载源码或发布页中的 ZIP，并解压到固定位置；安装后不要删除该文件夹。
2. 在 Chrome 地址栏打开 `chrome://extensions`。
3. 打开右上角的“开发者模式”。
4. 点击“加载已解压的扩展程序”。
5. 选择解压后直接包含 `manifest.json` 的文件夹。
6. 如果安装过旧版，请在扩展页面先移除旧版；然后完全关闭并重新打开已安装的“抖音”网页应用。

## 使用

正常在“抖音”网页应用里点击直播入口即可。直播间会覆盖在当前窗口中，不会新建弹窗。

点击左上角的“返回抖音”，或按 `Esc`，可以关闭直播间并回到之前的抖音页面。

直播播放后，点击播放器内置“开启小窗模式”、按 `U`，或使用左上角“小窗播放”，可打开 Chrome 视频画中画。再次操作可以关闭。输入聊天文字时不会拦截 `U`。

调节原有播放器的音量滑块或静音按钮即可同步，无需额外设置。同步范围为同一个抖音桌面窗口及其内嵌直播间，不跨独立窗口，不修改系统音量；页面完全刷新后重新以主页面播放器的音量为准。

扩展只在 `douyin.com` 页面运行，并且只处理 `https://live.douyin.com/` 地址。它不申请 Cookie、浏览记录或窗口管理权限。

## 已知限制

- Chrome 原生白色安全栏无法被扩展删除；本扩展通过在主站窗口内嵌直播页绕开它。
- 小窗显示直播视频画面，不包含聊天和礼物界面；关闭直播覆盖层或离开页面会结束小窗。需要浏览器允许视频画中画。
- 抖音的特殊按钮若不提供可识别的直播地址，浏览器会阻止它越级跳转；普通直播链接仍会在当前覆盖层内切换。
- 如果抖音以后禁止主站内嵌直播页，这种同窗口方案将失效。
- 若网站以后更改地址或打开逻辑，扩展可能需要更新。

## 隐私与权限

扩展只在 `douyin.com` 与 `live.douyin.com` 页面注入本地脚本，用于处理直播链接、同窗口显示和媒体暂停。扩展不包含远程代码，不申请 Cookie、浏览历史、下载或窗口管理权限。

音量同步只在主页面和当前内嵌直播间之间传递音量数值与静音状态，检查消息来源窗口与域名；这些设置仅保存在当前页面内存中，不上传服务器。
